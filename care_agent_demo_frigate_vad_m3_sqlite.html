Care Agent Demo — Context / World State

新版 Demo 核心：攝影機只是有限感知來源。Context / World State Agent 先整理「知道／不知道」與目前狀態；資料不足時，Resident Interaction Agent 以低侵入方式詢問；確認後建立記憶與提醒，再由 Caregiver Agent 產生日誌、趨勢與值得注意事項。
最終 Demo 架構：Frigate 接手本地影像基礎設施，只負責 24/7 camera ingest、motion / object activity、tracking、recording、snapshot / clip 與事件輸出；麥克風 24/7 開著，Silero VAD 只在有人說話時啟動 Whisper Large V3。只要 Frigate 產生值得處理的 candidate event，就把事件畫面 + 最近 10–15 秒 transcript + Fake Health + State 一起送給 MiniMax M3。M3 負責真正的多模態理解、Agent 決策、記憶與 Tool Calling。
舊版主流程：Frigate candidate event → 最近 transcript + 事件畫面 → MiniMax M3 單一大腦 → 直接操作所有工具。 舊版節點仍保留在下方並以刪除線標示，方便比較架構演進。
